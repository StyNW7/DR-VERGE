# simple-notebook/

Run pendahulu DR-VERGE dengan protokol yang lebih ringkas. **Bukan sumber angka paper** — perannya sebagai bukti pendukung.

## Isi

| Berkas | Keterangan |
|---|---|
| [`RESULTS_OVERVIEW.md`](RESULTS_OVERVIEW.md) | Ringkasan hasil dalam bahasa Inggris |
| [`OVERVIEW_ID.md`](OVERVIEW_ID.md) | Ringkasan hasil dalam bahasa Indonesia |
| `full_pipeline_notebook_simple.ipynb` | Notebook yang benar-benar dieksekusi |
| `outputs/` | Konfigurasi, partisi, tabel, gambar, metrik, dan prediksi per sampel |

## Peran run ini

Run *simple* memakai resolusi masukan dan protokol statistik yang berbeda dari run final, sehingga **angkanya tidak sebanding** dengan run *enhanced* dan tidak boleh dicampur dalam satu tabel.

Nilainya terletak pada satu hal: peringkat fidelitas mekanisme CSD yang muncul pada run final **juga muncul di sini**, pada protokol yang berbeda. Replikasi lintas protokol itulah yang memperkuat temuan utama penelitian.

Untuk hasil final, lihat [`../enhanced-notebook/`](../enhanced-notebook/).
