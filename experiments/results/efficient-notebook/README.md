# efficient-notebook/

Varian hemat komputasi dari pipeline DR-VERGE. **Bukan sumber angka paper** — dipertahankan untuk keterlacakan proses penelitian.

## Isi

| Berkas | Keterangan |
|---|---|
| [`RESULTS_OVERVIEW.md`](RESULTS_OVERVIEW.md) | Ringkasan hasil run ini |
| `full_pipeline_notebook_final_last_efficient.ipynb` | Notebook yang dieksekusi |
| `DR-VERGE_export_and_figure_fix.ipynb` | Notebook pendamping untuk ekspor artefak dan perbaikan gambar |
| `outputs/` | Konfigurasi, partisi, dan arsip hasil |

## Catatan

Sebagian besar keluaran run ini tersimpan dalam bentuk arsip `.zip` di dalam `outputs/`, bukan sebagai berkas terpisah. Untuk hasil yang dipakai dalam paper, lihat [`../enhanced-notebook/`](../enhanced-notebook/).

Angka run ini memakai protokol berbeda dan **tidak sebanding** dengan run final.
